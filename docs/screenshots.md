## Main window

The latest workshop items, the Tux Edition release news beside the KeeperFX team's, and everything else one
click away: Settings, Mods, the Workshop browser and the map editor.

![The main window: latest workshop items, latest news, and the buttons on the right](img/launcher-1.4.0.6021.png)

## Workshop browser

The whole [keeperfx.net](https://keeperfx.net) workshop inside the launcher: filter by category, sort by
rating or downloads, search by name, and install with one click. What you already have is marked.

![Workshop — browse & install: maps sorted by rating, with Details and Install buttons](img/launcher-1.4.0.6021-workshop.png)

The **Installed** tab lists what you actually have, KeeperFX's own content and your Workshop or other
add-ons alike, and uninstalls reversibly.

![Workshop — Installed: installed campaigns, each marked KeeperFX stock or Workshop/user, with Uninstall](img/screens/workshop-installed-6021.png)

## Mod Manager

Mods load from top to bottom; switch each one on or off, and **Install…** takes a `.7z`, `.zip` or `.rar`
from anywhere.

![Mod Manager: three mods with thumbnails and Enabled switches, and an Install button](img/screens/mods-6021.png)

## Settings

Every setting of the game and the launcher, on eight tabs. A control is greyed out when the installed
engine is too old for it. **Restore Defaults** returns the settings to their defaults, and **Save** writes
the changes.

### Game

Language, the intro and splash screens, cheats, censorship, screenshot format, replays (size limit and
how many to keep per campaign, free play and multiplayer), turns per second, and launch options.

![Settings, Game tab](img/screens/settings-game-6021.png)

### Graphics

Resolution and window mode for each of the three in-game views, the menu, movies and failsafe; display
monitor, frame-rate cap, movie scaling, smoothing, the renderer (software or OpenGL), VSync, creature
flower, hand and selection sizes, blink and flash rates, the map fade and the viewport mode.

![Settings, Graphics tab](img/screens/settings-graphics-6021.png)

### Sound

Sound on or off, CD music instead of your own files, pausing music with the game, muting when the window
is not focused, and how often and how loud the atmospheric sounds are.

![Settings, Sound tab](img/screens/settings-sound-6021.png)

### Input

Raw mouse input and sensitivity, relative mouse mode, when the cursor is released from the window, edge
panning, zooming and rotating around the cursor, the maximum zoom distance, and how the tag mode works.

![Settings, Input tab](img/screens/settings-input-6021.png)

### Multiplayer

Matchmaking on or off, the matchmaking server, and the port for multiplayer games.

![Settings, Multiplayer tab](img/screens/settings-multiplayer-6021.png)

### Launcher

The launcher's language, website integration and crash reports, opening on the same screen as the game,
the folder name in the window title, the **release channel** (stable or alpha), update checks and
automatic updates, backing up saves before an update, the Play button's
colour, the launcher's size, and removing files a new version no longer needs.

![Settings, Launcher tab](img/screens/settings-launcher-6021.png)

**Show launcher command line options** lists every option the launcher accepts when started from a
terminal:

![The launcher's command line options](img/screens/command-line-options-6021.png)

### API

The game's local API, for tools that talk to a running game, and its port.

![Settings, API tab](img/screens/settings-api-6021.png)

### About

The versions of the game, the launcher and its libraries, and the KeeperFX contributors and translators.

![Settings, About tab: versions, libraries and the KeeperFX contributors](img/screens/settings-about-6021.png)

## Play menu

The arrow beside **Play**: connect to a multiplayer game directly, watch a replay file, start without
mods, read the logs, or fetch the soundtrack.

![The Play menu: Direct connect, Run packetfile, Start without mods, View logs, Download music](img/screens/play-menu-6021.png)

**Direct connect (MP)** joins an open multiplayer lobby by the host's IP address and port:

![Direct Connect: IP address and port, Cancel and Connect](img/screens/direct-connect-6021.png)

**View logs** shows the launcher's log and the game's side by side, following live, with Copy, Open folder
and Refresh (part of the log is blurred here: it showed folder paths on the machine it was taken on):

![The log viewer: Launcher and Game tabs, the launcher log, Copy, Open folder, Refresh and Close](img/screens/log-viewer-6021.png)

**Download music** fetches the soundtrack when your copy of the game came without it:

![Download Music Files: why the music is missing, Cancel and Download](img/screens/download-music-6021.png)

**Run packetfile** opens a file picker for a replay, and **Start without mods** starts the game with every
mod switched off.

## Update check

The clock button checks for a new release on your channel straight away (the launcher also checks on its
own, as set on the Launcher tab):

![No updates at this time — you're on the latest version](img/screens/update-check-6021.png)

## Map editor

**Map Editor** installs [Unearth](https://github.com/rainlizard/Unearth), the community's map editor, the first
time, and starts it after that.

![Download Map Editor: the launcher offers to download and install Unearth](img/screens/map-editor-6021.png)
